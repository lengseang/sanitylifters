# Lifting Guides & Tutorials

A visual library that teaches every lift with images and short video tutorials.

## Problem

Text cues don't stick — people learn a lift by seeing it, not reading about it.

## Target user

- **The visual learner** who needs to see a movement before trying it.
- **The form-checker** who wants a quick reference between sets.
- **The new exerciser** who doesn't know what a movement should look like.

## Why now

Short-form video is already how most people learn movement; curating it beats
producing it from scratch.

## Core experience

1. A guide per lift and per muscle group.
2. Image breakdowns: setup, execution, common mistakes.
3. Video tutorials, embedded from existing sources first.

## User stories

- As a visual learner, I want a clean video of the lift, so I can copy it before
  I try it.
- As a form-checker, I want a quick image reference between sets, so I fix myself
  on the spot.
- As a beginner, I want to know the common mistakes, so I avoid them from day one.

## MVP scope

**In:** a curated set of guides for the main lifts, image + embedded video.

**Out:** original production, full exercise library, interactive overlays.

## Success metrics

- Tutorial completion and return rate.
- Guides viewed → session logged conversion.
- Search and browse depth.

## Risks

- **Content licensing** — curate/embed before producing original media.
- **Stale or low-quality content** — a wrong tutorial is worse than none.

## Open questions

- Do we license existing content or produce our own?
- Should guides link back into AI Form Coach for live feedback?
